ToYu 项目规范总集
==================

═══════════════════════════════════
一、打包规范
═══════════════════════════════════

1. 版本号：每次功能更新 +0.01，命名 YoTu0.XX.zip（如 YoTu0.31.zip）
2. 输出位置：C:\Users\34338\Desktop\003\
3. 每满 10 个版本，创建文件夹（如 0.21-0.30）归档

打包步骤：
  a. 检查 ToYu.spec 的 datas，确保新资源已加入
  b. cd desktop-pet && python -m PyInstaller ToYu.spec --noconfirm
  c. 创建 zip：
     - 根目录：ToYu.exe、changelog.txt
     - desktop-pet/ 子目录：main.py、requirements.txt、changelog.txt、
       image_processor/、pet_engine/、resources/、ui/
  d. 放到 C:\Users\34338\Desktop\003\

═══════════════════════════════════
二、代码规范
═══════════════════════════════════

1. 默认不加注释，只在 WHY 不明显时加简短注释
2. 不加多行 docstring，不加规划/决策/分析文档
3. 优先编辑已有文件，不新建不必要的新文件
4. 不过度抽象，三行重复代码好过一个过早的抽象
5. 不为不可能发生的场景加错误处理/回退/验证
6. 不用 feature flags 或向后兼容 shim
7. 不加当前 PR/任务/调用方相关的注释
8. 小批量迭代，每完成一个功能就打包

═══════════════════════════════════
五、PetState / AnimationType
═══════════════════════════════════

状态：IDLE → WALKING / HOPPING / INTERACTING / FALLING → SITTING → IDLE
      随时可进入 DRAGGED

动画：IDLE(呼吸眨眼) / WALK(摇摆) / FALL(旋转) / SIT(下压0.3s)
      INTERACT(弹跳0.3s→IDLE) / HOP(三阶段0.5s→IDLE)

三阶段跳跃：0-30%蹲下 → 30-60%起跳 → 60-100%落地

六、添加新功能的模式
═══════════════════════════════════

新增气泡按钮：
  1. PetFunctionBubble 加 pyqtSignal()
  2. _init_ui 加按钮（_make_btn / _make_small_btn）
  3. 如有状态切换逻辑，加 set_xxx() 公开方法
  4. PetWindow._show_function_bubble 连接信号
  5. HouseWindow._show_function_bubble 转发信号

新增动画：
  1. AnimationType 枚举加成员
  2. set_animation() 初始化
  3. update() 加 elif 块，用 elapsed 计算 transform
  4. 一次性动画末尾 auto-transition → IDLE

新增状态：
  1. PetState 枚举加成员
  2. transition_to() 加 entry 逻辑
  3. update() 加处理块（放在 IDLE/WALKING 之前）
  4. on_mouse_click() 加排除条件

新增设置：
  1. settings_manager.py 加 property getter/setter
  2. 布尔值用 isinstance(val, str) → val.lower() == "true" 兼容 QSettings
