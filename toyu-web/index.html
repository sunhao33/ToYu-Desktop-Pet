正在获取下载地址…

  1. 下载 zip 压缩包
  2. 解压到任意目录（建议不要放在系统盘根目录）
  3. 双击 ToYu\ToYu.exe 启动
  4. 想用 AI 功能：右上角「设置 → AI」填入你自己的 API Key
关于杀毒软件误报：部分安全软件可能对打包后的程序报警，这是打包工具的常见误报。 ToYu 不写注册表启动项、不上传你的数据，源代码完全公开可供审查。
需要什么配置？

Windows 10/11 64 位；约 300 MB 磁盘空间。纯本机功能（计时、报告、目标、拼豆） 无需联网、无需独显。AI 对话需要你自备 API Key。

我的数据会被上传吗？

不会。计时、屏幕统计、待办、记忆都存在你本机的用户目录。 只有你主动使用 AI 功能时，相关文本才会发给你自己配置的模型服务。

为什么叫「土豆」？

因为它默认就是一颗圆土豆 —— 你可以导入任意图片，或自己用内置的拼豆编辑器画一只， 把它换成你想要的任何样子。
