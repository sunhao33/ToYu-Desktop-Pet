Git 提交代码到 GitHub 完整流程
================================

一、初始化仓库
-------------
cd 你的项目文件夹
git init
git config user.name "你的GitHub用户名"
git config user.email "你的邮箱@example.com"


二、创建 .gitignore（排除不想提交的文件）
--------------------------------------
__pycache__/
*.pyc
*.zip
build/
dist/
.idea/
.vscode/
*.pdf
.env


三、暂存 + 提交
--------------
git add -A                    暂存所有文件
git status                    检查暂存区（有没有敏感文件？）
git commit -m "提交说明"       提交到本地仓库


四、推送到 GitHub
-----------------
gh auth status                确认已登录

gh repo create 仓库名称 \
  --description "简介" \
  --public \
  --push \
  --source=.

（如果是已有仓库）：
git remote add origin https://github.com/用户名/仓库名.git
git push -u origin master


五、后续更新
----------
git add -A
git commit -m "描述改了什么"
git push


避坑要点
--------
1. git init 要在项目根目录执行，不要在用户目录执行
2. .gitignore 要在 git add 之前写好，否则排除不掉
3. 每次提交前用 git status 检查，确保没有 API key、密码等敏感信息
4. 如果暂存了不该提交的文件：git rm --cached 文件名
