# YoTu UI 优化方案 v0.31

## 修改目标
- 紧凑化布局，提升空间利用率
- 增强状态信息可视化
- 优化按钮层级和交互体验
- 功能页面卡片化

## 修改清单

### 1. 主窗口布局重构
- [ ] 收藏夹区域紧凑化（48x48 缩略图）
- [ ] 状态信息可视化（好感度进度条、心情图标）
- [ ] 操作按钮层级优化
- [ ] 功能页面卡片化布局

### 2. 样式优化
- [ ] 统一圆角和阴影
- [ ] 增加卡片层次感
- [ ] 优化颜色对比度

### 3. 新增组件
- [ ] 好感度进度条组件
- [ ] 心情状态图标
- [ ] 时间段显示优化

## 文件修改列表
- `ui/main_window.py` - 主要 UI 代码
- `pet_engine/pet_window.py` - 宠物窗口状态显示
- `resources/` - 新增图标资源

## 打包说明

```bash
pyinstaller ToYu.spec
```
