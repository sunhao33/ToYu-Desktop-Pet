ToYu 打包规范
=============

## 版本号
- 每次功能更新 +0.01，changelog.txt 最上面写一条 `v0.XX (日期)`
- 打包脚本从 changelog.txt 自动读取版本号，不需要改脚本

## 输出位置
- zip 输出到项目根目录（desktop-pet 的上一级），命名 `ToYu_v0.XX.zip`
- 例：`TUYO文件\tuyo\ToYu_v0.65.zip`

## 打包步骤

### 1. 更新 changelog
- 在 desktop-pet/changelog.txt 顶部插入本次版本条目

### 2. 检查资源列表
- ToYu.spec 的 datas 需包含 resources/ 下所有新图片、音频、配件 png

### 3. 构建 exe
```bash
cd desktop-pet
python -m PyInstaller ToYu.spec --noconfirm
```
产物：`desktop-pet/dist/ToYu.exe`（约 67 MB，单文件）

### 4. 打包 zip
```bash
cd desktop-pet
python _package.py
```
自动完成：复制 exe + changelog 到根目录，附带完整源码到 `desktop-pet/`，
排除 build/dist/__pycache__/临时脚本，最后打印条目数与根目录内容。

### 5. 验证
- zip 根目录含：ToYu.exe、changelog.txt
- zip 内 `desktop-pet/` 含：main.py、requirements.txt、changelog.txt、
  image_processor/、pet_engine/、ui/、resources/、ToYu.spec
- 双击 exe 能起（首次启动默认从收藏夹里的 ToYu / TV 小电视开始）

## 依赖
- 运行：PyQt6、Pillow、numpy（rembg + onnxruntime 仅 AI 抠图需要）
- 打包：pyinstaller
- `.gitignore` 排除 *.zip / build / dist，exe 不进 git，只进发布包
