# ToYu · 桌面土豆宠物 🥔

> 一只住在桌面上的像素宠物，也是一个**能替你办事的桌面智能体**。
> 记录你的专注时间，生成学习/工作报告，管理日程待办 —— 并能通过大模型
> **自主调用工具、多步执行、记住你的长期习惯**。

## 这是智能体，不只是桌宠

多数桌面宠物止步于"会动、会卖萌"。ToYu 把宠物当作**交互外壳**，
内核是一套完整的智能体运行时：

| 能力 | 实现 |
|---|---|
| **工具调用** | 模型可自主调用本机工具：查桌面状态、读写待办、设目标、生成报告 |
| **多步执行** | 最多 5 轮自主循环，每轮观察结果再决定下一步，留下完整执行轨迹 |
| **长期记忆** | 20 个受控记忆槽位；**不信模型自报的置信度**，从证据文本重新估算 |
| **上下文注入** | 6 个优先级块的桌面状态（待办 > 学习情况 > 日程 > 宠物状态 > 当前应用 > 剪贴板），token 预算内自动裁剪 |
| **线程安全** | 子线程跑 Agent 主循环、主线程执行 Qt 工具调用，三条刹车（轮数/单次超时/总超时）防止失控 |

### 三条工程纪律

1. **不该用模型的地方就不用**
   统计、阈值、规则判定全部由代码完成；模型只做"非结构化文本 → 结构化数据"
   和"语言组织"两件事。不配 API Key 时全部本机功能照常可用。

2. **不信模型说的话**
   记忆的置信度由代码从证据重新估算；报告的数字只从已有接口读取，
   禁止模型自己造数字；工具参数经 JSON Schema 强校验，非法就回灌让它重试。

3. **出问题不能拖垮主流程**
   记忆、AI 上下文、报告分析都有三级降级；任何一层失败只影响该功能本身。

## 完整功能

**学习工作**
- **学习/工作报告** — 日/周/月汇总：有效学习时长、应用分布、时段规律、完成任务数；支持基础版（纯本机）与 AI 版（深度分析），可导出 Markdown
- **心流模式** — 番茄轮次、休息机制、今日专注时间轴；计划栏每项任务独立计时
- **每日目标** — 进度环实时反映达成度，按天记住历史表现
- **屏幕时间统计** — 应用排行、时段分布、较昨日对比

**桌面伙伴**
- 透明窗口 + 60fps 动画 + 物理引擎（重力/落地/边缘碰撞）
- 好感度系统，8 种互动，每日上限与里程碑
- 时间感知（夜晚变暗变慢）、天气感知（下雨撑伞、高温吃冰淇淋）
- 7 种配件、粒子特效（爱心/星星/音符/雪花/雨滴）
- 像素小房子，宠物可进出

**创作**
- **拼豆编辑器** — 51 色调色板手绘像素宠物；导入任意图片自动抠图 + 颜色量化
- 作品集收藏夹，随时切换桌面伙伴

## 快速开始

```bash
cd desktop-pet
pip install -r requirements.txt
python main.py
```

**环境**：Windows 10/11 64 位 · Python 3.10+（开发环境为 3.14）

**启用 AI 功能**：启动后「设置 → AI」填入你自己的 API Key
（兼容 DeepSeek / OpenAI 等 OpenAI 格式接口）。**不填也能用，只是没有 AI。**

## 关键设计决策

<details>
<summary><b>为什么桌面宠物要做智能体？</b></summary>

桌宠天生是"陪伴"场景，而陪伴最缺的是**记得住、能办事**。
把智能体内核塞进宠物外壳后，用户不用切窗口、不用打开新软件 ——
直接跟桌面上那只说话，它就能查你的学习情况、加待办、生成报告。
宠物提供了低成本的自然交互入口，这是纯聊天窗口给不了的。
</details>

<details>
<summary><b>为什么不用向量数据库做记忆？</b></summary>

只有 20 个受控槽位，用字符 2-gram + 时间衰减的相关度就够，
且**可解释、零依赖、可预测**（MIN_RELEVANCE=0.08, MIN_SCORE=0.18）。
引入向量库会让安装包暴涨上百 MB，收益却不成正比。
槽位受限反而避免了"记忆无限膨胀变成噪音"。
</details>

<details>
<summary><b>怎么防止模型乱来？</b></summary>

- **参数强校验**：工具参数走 JSON Schema，类型/长度/取值范围都查，失败把原因回灌让模型重试
- **三条刹车**：最多 5 轮、单工具 20 秒、整轮 90 秒；连续失败 2 次即停
- **提示注入防护**：窗口标题、剪贴板等外部文本进入上下文前做标记，不当作指令
- **置信度重估**：显性信号（"我叫…""记住…"）>=0.90，弱信号 >=0.70，否则压到 0.60 以下
</details>

<details>
<summary><b>崩溃了怎么办？</b></summary>

`main.py` 装了崩溃守卫：未捕获异常写进 `%APPDATA%/ToYu/errors.log`，
程序**继续运行**不退出，并在气泡里提示一句。日志超 512KB 自动轮转。
（这个机制本身也在测试里覆盖 —— 有专门的假异常注入用例。）
</details>

## AI 使用披露

本作品在开发过程中**使用 AI 辅助编写代码**（详见《软件创意设计文档》）。

运行时的 AI 能力与开发时的 AI 辅助是两件事：

- **运行时**：需用户自行配置 API Key 才会启用；不配置时全部本机功能正常可用
- **数据流向**：计时、屏幕统计、待办、记忆全部存在本机用户目录；
  只有你主动使用 AI 功能时，相关文本才会发给你自己配置的模型服务
